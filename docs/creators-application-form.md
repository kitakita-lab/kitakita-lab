# 作家・つくり手・事業者 応募フォーム（Google フォーム）の仕様と公開手順

`/creators` の応募窓口に使う Google フォームの設問と、作成から公開までの手順。
**フォームの作成・公開・応募受付の開始は、ユーザーが行う**（Claude Code の環境には Google フォームを作成・設定するツールがない）。

## サイト側の状態

- `src/data/creators.ts` の `creatorApplication` が `formUrl: null`・`privacyPolicyPath: null` の間、
  `/creators` は「応募フォームは、現在準備中です」と表示し、フォームへのリンクを出さない。
- 両方を設定すると「応募フォームへ」のボタンとプライバシーポリシーへのリンクが表示される
  （`isApplicationOpen()`。URL は `https://docs.google.com/forms/` または `https://forms.gle/` だけ許可）。
- PRIZMA などで案内する URL は、フォームの URL ではなく **`https://www.kitakita-lab.com/creators`** を推奨
  （フォームを作り直しても案内先が変わらない。募集の前提と個人情報の取り扱いを読んでから応募してもらえる）。

## 設問

フォームのタイトル: 「KitaKita Lab 作家・つくり手・事業者の応募フォーム」

説明文（案）:

> 今後のワークショップや体験イベントでご一緒できる方との出会いを目的とした募集です。
> 応募いただいても、案件のご依頼・採用・契約・出店の機会をお約束するものではありません。
> 内容を拝見し、ご一緒できそうな機会があるときに、メールでご連絡します。

| # | 設問 | 形式 | 必須 |
|---|---|---|---|
| 1 | 氏名または活動名 | 記述式（短文） | ○ |
| 2 | メールアドレス | 記述式（短文）・回答の検証「メールアドレス」 | ○ |
| 3 | 活動内容・ジャンル | 段落 | ○ |
| 4 | 提供できる体験と所要時間 | 段落（例: 「フラワーボトルづくり／1組10〜15分」） | ○ |
| 5 | 作品・SNSのURL | 段落（複数可） | ○ |
| 6 | 対応できる地域・曜日 | 段落 | 任意 |
| 7 | 個人情報の取り扱いへの同意 | チェックボックス 1 項目「プライバシーポリシー（URL）を確認し、同意します」 | ○ |

設問 7 の説明にプライバシーポリシーの URL（公開後）を入れる。

## 設定（推奨）

- 回答者のメールアドレスの自動収集: **オフ**（設問 2 で受け取る。Google へのログインを求めないため）
- 回答を 1 回に制限: **オフ**（オンにすると Google へのログインが必要になる）
- 回答のコピーを回答者に送信: 任意（送る場合は「リクエストされた場合」）
- 回答の保存先スプレッドシート: KitaKita Lab のアカウントの限定公開。共有範囲を必要な人だけにする
- 新しい回答のメール通知: オン（受付漏れを防ぐ）

## 公開までの手順（ユーザーが行う）

1. プライバシーポリシーの内容を確定する（`docs/privacy-policy-draft.md` の【要確認】をすべて解消。必要に応じて専門家に確認）。
2. プライバシーポリシーのページをサイトに追加する（Claude に依頼可。公開はユーザーの承認後）。
3. 上の仕様で Google フォームを作成する（Google フォーム → 空白のフォーム）。
4. テスト回答を 1 件送り、スプレッドシートと通知を確認してから、テスト回答を削除する。
5. 「送信」→ リンク → URL を短縮 で URL を取得し、Claude に伝える（`creatorApplication.formUrl` と `privacyPolicyPath` を設定する PR を作る）。
6. PR の内容とプレビューを確認し、マージを承認する。マージ後、本番の `/creators` でボタンとリンクを確認する。
7. 回答の受付を開始する（フォームの「回答を受け付ける」）。PRIZMA には `https://www.kitakita-lab.com/creators` を案内する。
